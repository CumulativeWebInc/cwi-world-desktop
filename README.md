# CWI World Desktop

The Gear Ledger 3D world as a desktop app, with the **KingCode Console** voice command deck built in.

- 👑 In-world button opens a docked KingCode chat panel
- 🎙 "Hey KingCode" local/offline wake word + local speech recognition
- 🔔 KingCode → you pings (in-world + OS notifications)
- 🔒 Voiceprint speaker verification, presenter mode, privacy tiers — voice alone can never spend, sign, or publish
